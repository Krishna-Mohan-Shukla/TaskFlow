**TaskFlow** is a full-stack MERN application designed to streamline project and task management within an organization.

The system provides separate dashboards for **Admin** and **Employee** users with role-based authentication and authorization.

**Key Features:**

* Secure user authentication using JWT.
* Role-based access for Admin and Employees.
* Admin can create, update, delete, and assign projects/tasks to specific employees.
* Employees can view only their assigned tasks.
* Start/Stop work timer to track actual working time on each task.
* Update task progress and mark tasks as completed.
* Real-time task status management (Pending, In Progress, Done).
* Admin dashboard to monitor project progress and assign new tasks after completion.
* CRUD operations for project management.
* RESTful APIs built with Express.js.
* MongoDB database integration using Mongoose.
* Responsive React frontend with modern UI.

**Tech Stack**

* Frontend: React.js, React Router, Tailwind CSS
* Backend: Node.js, Express.js
* Database: MongoDB
* Authentication: JWT
* API Testing: Postman
